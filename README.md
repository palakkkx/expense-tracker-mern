# 💰 Expense Tracker MERN

A full-stack Expense Tracker application built using the MERN stack. It helps users manage their income and expenses through a simple and user-friendly interface.

## 🚀 Features

- User Registration and Login
- JWT Authentication
- Protected Routes
- Add Income and Expenses
- View Transactions
- Edit Transactions
- Delete Transactions
- Dashboard with Balance, Income and Expense Summary
- Analytics Page
- Profile Page
- Responsive User Interface
- MongoDB Database
- REST API
- Live Deployment

## 🛠️ Technologies Used

- React.js
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Axios
- React Router
- Tailwind CSS
- Git & GitHub
- Vercel

⚙️ Installation
1. Clone the Repository
git clone https://github.com/palakkkx/expense-tracker-mern.git
2. Go to the Project Folder
cd expense-tracker-mern
3. Install Frontend Dependencies
cd client
npm install
4. Install Backend Dependencies
cd ../server
npm install
🔐 Environment Variables

Create a .env file inside the server folder.

MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
PORT=5000

Do not upload your .env file to GitHub.

▶️ Run the Project Locally
Start Backend
cd server
npm start
Start Frontend

Open another terminal:

cd client
npm run dev

The application will then run locally.
